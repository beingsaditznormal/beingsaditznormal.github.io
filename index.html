Hi reader. I'm a guy from the northern part of Italy — Cesano Maderno, Lombardia, to be precise about it. I started out in Physics, then Engineering Physics, then decided that if you are not yet a liquid, you should start to liquify — so I did, and ended up in data. No regrets.

I'm living, cycling, reading, computing and talking to the machines. I don't know if I put them in the right order.

Right now I'm a Data Associate at Cegeka, where the work sits somewhere between engineering and research: building pipelines that ingest the unstructured, making LLMs talk to databases, and occasionally convincing a RAG system to actually retrieve the right thing. It's more interesting than it sounds. And it already sounds interesting. xx

✦

What I work on

Data Engineering
Pipelines, lakehouses, medallion architectures. The unglamorous plumbing that makes everything else possible — and that breaks in interesting ways when it does break.
LLMs & RAG
Building systems where language models actually do useful things: Text2SQL modules, conversational interfaces, VLM-powered extraction. LangChain and LangGraph are the current tools of choice.
Machine Learning
From anomaly detection on automotive NoSQL data to supervised classification on real clinical datasets. Training models, evaluating them honestly, and resisting the urge to celebrate before the test set.
Stack
Python first, always. SQL for when it has to be relational. MongoDB, Neo4J for when it doesn't. Databricks, Azure, Scikit-learn, TensorFlow — whatever the problem calls for.
